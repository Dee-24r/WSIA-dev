## Mike’s Recommendations

> I would recommend making a wishlist of items, a required list of items, and a general outline for them to follow. Below are some of my thoughts; feel free to use it while considering our asks to them.

### Live Radio Player

- Prioritize the live radio player that can be active between tabs and accessible to be played on mobile in the background while the phone is locked. **(MVP)**
  - Ask Laura for more information about a sniffer.
- “Listen now” button on every page to connect to the stream.
- Build a back-end that can connect to our future digitization that shows:
  - DJ Name
  - Show Name
  - Now Playing: Artist & Song
- Should work properly on desktop and mobile, especially if the tab isn’t active, so people can listen while working or walking.
- Stream visualiser that reacts to audio from the stream.

### Show Schedule

- An easy-to-edit WSIA back-end database connected to a good-looking front weekly calendar that showcases the following: **(MVP)**
  - DJ Name
  - Show Name
  - Description, if applicable
  - Genre/Category/Tag
    - In the past, we did genre-based shows
  - Show Decal
    - Some station DJs put their faces or do art for their show
  - Social Links
    - Some station DJs promote themselves via the website

### DJ Profiles

- Also easy to edit by WSIA via a back-end database.
- Should allow WSIA to add and archive profiles. **(MVP)**
- The DJ Name can link to a DJ profile that includes:
  - Name
  - DJ Name
  - Photo
  - Bio
  - CSI Program/Major
  - Expected Year of Graduation
  - Show Times
  - Genre Interest
  - Socials
- Separately, there should be station leadership / Board of Directors:
  - The above information
  - Their responsibilities
  - Contact information
- Alumni / Archive

### News & Content

- Easy to edit, add, and archive. **(Stretch)**
- Categories:
  - WSIA News

- Articles:

- Digital Archive
- SPN - Sponsorships:

- SMID / Sweepers:

- Interviews:

### Admin Dashboard

- **(Stretch, but also important)**
- We should be able to maintain the site without actually editing HTML/CSS/JavaScript.
- Authorized Users / Administrators / Moderators Login
- Create / Edit / Archive / Delete functionality for everything from:
  - Shows
  - Articles
  - DJ Profiles
  - News and Announcements
- Analytics:
  - Page Views
  - Measurable across the website from things like the stream, articles, underwriting, etc.
  - Unique Visitors
  - Popular Pages
  - Listen Live click data
  - Stream start and end
  - Listening duration

### Header & Footer

- Simple MVP

  - Join

  - Search should be able to go across the public website, excluding archived pages.
- Social Media and Contact Info should be available at the footer.
